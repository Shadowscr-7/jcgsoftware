# 🚀 Portfolio Profesional - Desarrollador Full Stack

Portfolio profesional moderno construido con las últimas tecnologías web 2026.

## ✨ Stack Tecnológico

- **Next.js 15** - Framework React con App Router
- **React 19** - Biblioteca UI
- **TypeScript** - Type safety
- **Tailwind CSS 4** - Styling
- **Framer Motion** - Animaciones
- **Shadcn/ui** - Componentes UI
- **Three.js** - Gráficos 3D (próximamente)
- **GSAP** - Animaciones avanzadas (próximamente)

## 🎨 Características

- ✅ Tema Dark profesional con colores vibrantes
- ✅ Animaciones fluidas y modernas
- ✅ Navegación suave entre secciones
- ✅ Responsive design
- ✅ Efectos glassmorphism
- ✅ Gradientes animados
- ⏳ Timeline de experiencia interactiva (próximamente)

- ⏳ Formulario de contacto (próximamente)

## 🚀 Inicio Rápido

### Instalación

```bash
npm install
```

### Desarrollo

```bash
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000) en tu navegador.

### Build para Producción

```bash
npm run build
npm start
```

## 📁 Estructura del Proyecto

```
profile/
├── app/                 # Next.js App Router
│   ├── layout.tsx      # Layout principal
│   ├── page.tsx        # Página home
│   └── globals.css     # Estilos globales
├── components/
│   ├── sections/       # Secciones del portfolio
│   ├── shared/         # Componentes compartidos
│   ├── animations/     # Componentes de animación
│   └── ui/            # Componentes UI (shadcn)
├── lib/
│   ├── constants.ts    # Constantes
│   ├── utils.ts       # Utilidades
│   └── data/          # Datos del portfolio
├── hooks/             # React hooks personalizados
├── types/             # TypeScript types
└── public/            # Assets estáticos
```

## 🎨 Personalización

### Colores

Los colores del tema se definen en `app/globals.css`:

```css
--primary: #00D9FF (Cyan)
--secondary: #7B2FF7 (Púrpura)
--accent: #FF3366 (Rosa)
```

### Contenido

Actualiza el contenido en:
- `lib/constants.ts` - Información general
- `lib/data/` - Experiencia, proyectos, habilidades

### Imágenes

Agrega tus imágenes en:
- `public/profile.jpg` - Tu foto profesional
- `public/projects/` - Screenshots de proyectos
